# 게임성 개선 1차 구현 결과

작성일: 2026-09-17

## 구현 범위

[구현 계획](gameplay-improvement-plan.ko.md)의 1차 범위인 미션 집계·기억 앨범·단계별 해금을 구현했다.

- 미션은 프로필 전체의 **앱 활동 1개 + 서로 다른 돌봄 2종**으로 집계한다. AI 필수 조건을 없애고 펫 전환 후에도 진행을 유지한다.
- 완료 시 기억 카드를 하루 한 장 자동 지급한다. 일반 앱 활동도 하루 첫 인정 활동에 한 장을 남긴다. XP·돌봄일·용 해금 조건은 유지한다.
- 기억 앨범에 한국어·영어 템플릿 13개, 날짜·펫 필터, 25장씩 조회, 새로 고침을 제공한다. 메모 제목·본문·AI 응답은 복제하지 않는다.
- 2~5단계에서 인사·종별 자랑·함께 꿈꾸기·성장 축하 반응을 해금한다. 기존 소품·자세와 전용 대사를 사용하며 대시보드에서 다시 재생할 수 있다. 별도 원화나 새 스프라이트는 추가하지 않았다.
- 기존 성장 단계에 해당하는 콘텐츠는 유지하며 펫별 업데이트 기념 카드로 표시한다. 알 수 없는 과거 성장 날짜를 만들어 내지 않는다.
- 지급 원장과 앨범·해금을 같은 SQLite 트랜잭션에 저장한다. 돌봄 요청 ID, 정책 버전과 독립적인 지급 키로 중복을 막는다. 앱 활동은 발행 시 펫을 캡처하여 큐 대기 중 펫 변경에 영향을 받지 않게 했다.
- 새 기능의 UI와 저장 로직은 별도 파일로 분리했다. 기존 화면 전체를 다시 설계하지 않았다.

| 앨범 | 페이지·필터·저장 필드, 두 언어 템플릿과 반응 대사 길이 검증 |

| 패키지 시작 검사 | `--data`로 실제 메모와 분리된 경로에서 8초 실행 후 정상 생존 확인 |

이번 자동 검증에는 앨범 창의 실제 클릭·스크린 리더 조작·모든 DPI/테마에서의 시각 검사가 포함되지 않는다.
장기 플레이에서 보상감과 방해 정도가 적절한지도 아직 검증하지 않았다. 배포본 시작 검사는 이 항목들을 대체하지 않는다.

## 다음 단계

성격 표현과 공 던지기 미니게임은 아직 구현하지 않았다. 다음 구현에서는 성향의 최소 표본·동률·전환 규칙,
전용 대사·행동, 미니게임 세션 ID와 완료 시 한 번만 지급하는 경계를 다룬다. 방·취향·주간 목표와 이후 기능도
별도 단계로 남아 있다. 1차의 접근성·화면 검증과 사용성 관찰 결과를 후속 범위에 반영한다.
